⚠️ Test Frontend
This is a temporary test page. Open the browser DevTools console (F12) to test Tauri commands.

Available Commands

1. Discover Server

// Find running OpenCode server
const result = await window.__TAURI_INTERNALS__.invoke('discover_server');
console.log('Discovery result:', result);

2. Spawn Server

// Start new OpenCode server
const server = await window.__TAURI_INTERNALS__.invoke('spawn_server');
console.log('Server spawned:', server);

3. Check Health

// Check if server is healthy
const healthy = await window.__TAURI_INTERNALS__.invoke('check_health');
console.log('Server healthy:', healthy);

4. Stop Server

// Stop the connected server
await window.__TAURI_INTERNALS__.invoke('stop_server');
console.log('Server stopped');
